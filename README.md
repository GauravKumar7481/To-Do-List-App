# To-Do List App

A responsive task management web application built using React and Vite to help users organize tasks, schedule deadlines, set priorities, and track upcoming activities through countdown timers and browser notifications.

## Features

- **Task Management:** Add and delete tasks with ease.
- **Priority Management:** Assign priority levels to tasks.
- **Task Scheduling:** Set future dates and times for scheduled tasks.
- **Countdown Timer:** Track the remaining time until each task's deadline.
- **Browser Notifications:** Receive reminders for upcoming tasks.
- **Google Authentication:** Sign in using your Google account through Firebase Authentication.
- **State Management:** Manage application state using Redux Toolkit.
- **Local Storage:** Preserve task data across browser sessions.
- **Responsive UI:** User-friendly interface styled with Tailwind CSS.
- **PWA Support:** Includes Progressive Web App assets and service-worker functionality.

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- Redux Toolkit
- Firebase Authentication
- Local Storage
- React Toastify

## Getting Started

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Configure Firebase Authentication with your Firebase project credentials.
4. Start the development server using `npm run dev`.
5. Open the local URL displayed in your terminal.
